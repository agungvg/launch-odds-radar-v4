A token launch radar that prices every pre-token protocol from the snapshot's own figures — fitted peer multiples, a grid-fitted size exponent and shape terms, and fitted launch odds — ranks 198 protocols by expected value and gives each a costed six-step farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
